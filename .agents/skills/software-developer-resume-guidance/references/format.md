# Format and tone

- The generated resume is to be at most one page.
- Section headers e.g PROFESSIONAL SUMMARY should always be in upper-case, bold and it should have higher font size than text under any section.
- All mentions of tools and keywords under the "WORK EXPERIENCE" should be bold and same font size as other text under any section. Apply this to the bullets under the experience heading in the base resume (PROFESSIONAL EXPERIENCE).
- Keep the base document's section headings, order, alignment, and bullet numbering.
- Professional summary is one short paragraph. Keep four bullets for each job.
- Past tense, no first person, one idea per bullet.
- Plain wording. Spell an acronym on first use when the posting uses both the acronym and the full term.
